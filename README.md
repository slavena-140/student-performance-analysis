# Student Performance Factors (Data Analysis & Hypothesis Testing)

📅 **Date:** 4th Semester (Summer 2026)  
🌱 **Project Status:** Completed (Data Analysis & Python Academic Project)  
💻 **Environment:** Google Colab / Jupyter Notebook (`.ipynb`)  

A comprehensive, end-to-end data analysis study conducted in Python to analyze and uncover hidden socio-demographic, behavioral, and economic factors influencing student academic performance. The project demonstrates advanced competencies in exploratory data analysis (EDA), structural data cleaning, statistical hypothesis testing, and interactive data visualization.

---

## 🚀 Key Analysis Phases & Workflow

### 1. Data Ingestion & Pre-processing
- **Data Structuring:** Loaded raw survey metrics into a Pandas DataFrame infrastructure for systematic filtering.
- **Data Cleansing & Diagnostics:** Sanitized the dataset by identifying and handling missing boundaries, removing outliers, normalizing text inputs, and casting data types for memory efficiency.

### 2. Exploratory Data Analysis (EDA)
- **Descriptive Statistics:** Computed central tendency metrics (mean, median, mode) and dispersion characteristics (variance, standard deviation) across diverse student test score partitions.
- **Distribution Exploration:** Analyzed score spreads to diagnose skewness, utilizing automated binning rules to identify performance patterns.

### 3. Hypothesis Generation & Testing
- Formulated and verified multiple core data hypotheses to isolate critical academic triggers.
- **Socio-Economic Diagnostics:** Investigated structural correlations between parent educational background tiers and student GPA brackets.
- **Behavioral Triggers:** Tested behavioral impact factors (e.g., screen time usage, study hours per week, sleep cycles, and extracurricular involvement) against core examination marks.

### 4. Advanced Visual Analytics
- Generated high-impact data visualization plots utilizing `Matplotlib` and `Seaborn` to present statistical insights clearly:
  - **Correlation Heatmaps:** For quick feature dependency tracking.
  - **Box Plots:** To inspect distribution variations and outlier markers across behavioral splits.
  - **Scatter & Regression Plots:** Mapping real-time trends between active study duration and grading shifts.
